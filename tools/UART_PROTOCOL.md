# v48 / v49 Type-C 控制与字幕协议

板载 Type-C / CH340，115200 / 8N1，无流控；FPGA RX=F12、TX=D12。用于 v48 和 v49 管理固件，两者均使用协议版本 2；旧 Python 管理员协议不同，不可混用。v49 仅移除 HDMI 和管理界面的 ADC 显示，状态数据格式不变。

## 控制请求

`A5 5A CMD VALUE CRC_H CRC_L`。CRC16-CCITT-FALSE，poly=0x1021、init=0xFFFF、不反射、无最终异或，计算范围为 `CMD VALUE`，高字节在前。

| CMD | 用途 | VALUE |
| --- | --- | --- |
| 02 | 读取状态 | 0 |
| 20 | 指定图槽 | 0–4，对应界面第 1–5 张 |
| 21 | 音量 | 0–100 |
| 22 | 亮度 | 0–9 手动；FF 恢复光敏自动 |
| 23 | 对比度 | 0–9 |
| 24 | 自动轮播 | 0 暂停，1 启用 |
| 25 | 上一张 | 0 |
| 26 | 下一张 | 0 |
| 27 | 转场 | 0 四角展开，1 滑动，2 淡入淡出 |
| 28 | 可视化 | 0 频谱，1 波形 |
| 29 | 上位机音频暂停 | 0 释放暂停，1 暂停 |

非法命令、参数、CRC 或 100 ms 字节间超时返回 `15`，不执行控制。成功返回 `06`、12 字节状态、状态 CRC_H / CRC_L，共 15 字节。状态在控制寄存器更新后采集，CRC 只覆盖 12 个状态字节。成功表示命令已接收；请求图号和当前显示图号分开回读，可继续查询到切换完成。

## 状态数据

| 偏移（不含 ACK） | 内容 |
| --- | --- |
| 0 | 协议版本，固定 2 |
| 1 | 当前显示图槽 0–4 |
| 2 | 请求图槽 0–4 |
| 3 | 音量 0–100 |
| 4 | 生效亮度 0–9 |
| 5 | 对比度 0–9 |
| 6 | flags，见下文 |
| 7–8 | 原始 12 位 ADC，高字节在前 |
| 9 | 转场 0–2 |
| 10 | 可视化 0–1 |
| 11 | 锁存故障码；当前故障是否存在由 flags.bit4 表示 |

flags 从 bit0 到 bit7：手动亮度、轮播启用、实际音频启用、视频就绪、当前故障、缩放中、上位机暂停音频、光敏有效。

命令与物理按键共用原控制寄存器；同拍设置同一参数时串口优先。音频暂停与板载/遥控器暂停取或，因此释放上位机暂停不强制覆盖其他暂停来源。轮播开关只控制自动换图，手动前后/指定图号仍可用。状态轮询不算用户活动；设置参数后沿用约 30 秒无操作恢复自动亮度的既有策略。自动光敏常规更新沿用既有空闲策略，不改成连续更新；FF 在光敏有效时立即采用当前自动档位。

## 原字幕数据包

保留 `A5 5A 01 LEN [LEN*32 字模字节] CRC_H CRC_L`，LEN=0–64；CRC 覆盖 LEN 和字模数据，不含命令字。每字 16×16 单色，逐行两字节、最高位在前。LEN=0 恢复默认欢迎字幕，示例 `A5 5A 01 00 E1 F0`。仅在完整校验后、下一视频帧边界切换字库并单独返回 `06`；失败返回 `15`，旧字幕不变。

发送端须等待整条应答后再发下一条；完整字幕待帧提交或控制应答发送期间不接受新请求。CRC 在 UART 字节间隔内逐位计算，节省逻辑资源。状态帧有校验，错误明确报出，不自动重发、不降级。所有修改仅保存在易失寄存器/字库，无持久写入。
