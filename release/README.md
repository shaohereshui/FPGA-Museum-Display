# 安路赛题一｜作品发布说明

作品保留五图切换、轮播、音量、亮度、对比度、转场、频谱/波形、音频暂停及中文字幕功能。HDMI 和管理控制台不显示 ADC 诊断信息；光敏采样和自动亮度继续运行。

## 当前状态

TD 构建、时序检查、七组 RTL 仿真和上位机检查已通过。本版尚未由 Agent 下载到 SRAM 或 Flash，按用户要求仅交付文件，由用户自行烧录。

- [构建日志](build.log)、[时序结果](media_phy.ts)、[详细时序](media_pr.timing)、[完整校验记录](validation.json)。

## 管理控制台

[打开管理控制台](../tools/Open_Admin_Console.cmd)。历史 GUI 检查连接 COM5，确认界面无 ADC 标签；该连接使用当时板卡原先运行的固件，并不代表已加载本次发布的固件。解压后需选择实际 COM 口。Type-C / CH340，115200 8N1，FPGA RX=F12、TX=D12；串口协议仍为版本 2。

## 验证与实现

- 原 ADC 行所在的 3584 个像素全部透传验证通过，菜单数值及黑字显示回归通过。
- 六组 ADC、手动超时、按键、遥控、红外和菜单回归通过；真实 UART 控制仿真与上位机自检通过。
- 仅删除 OSD 诊断绘制逻辑、四个 OSD 输入及其连接和上位机 ADC 标签；光敏采样/滤波、自动亮度、UART、图片控制、引脚及时钟约束不变。
- 最终布局种子 23 完成 bitgen；SWNS=0.410 ns、HWNS=0.024 ns、STNS/HTNS=0，STA coverage=97.66%，ADC 时钟 13.500 MHz。布局后 4896/4900 MSlice、62/64 BRAM、29/29 DSP；布线后 4892 MSlice。已有厂商警告保留，不声称零警告或全部路径覆盖。
- 资源接近满载。种子 31 出现局部布线冲突，17 超容量；种子 5 在 23 成功后停止。仅调整构建布局种子，未为此修改功能代码或引入新架构。发布文件与通过的构建 bit 的 SHA-256 一致，78 个源码、ROM、约束和构建脚本与构建副本一致。

## 使用边界

红外供电接线于 2026-10-29 按用户要求改为 **VCC=J1-29 / 3.3 V，GND=J1-30 / GND**，已核对板卡 `4_GPIO.pdf`。断电后移动这两根线；OUT 保持原接线，当前 `ir_rx` 约束仍为 FPGA N4。此项仅为供电接线变更，本次发布的 bit 继续使用，无需修改代码或重新烧录；实物接线及遥控响应待用户确认。

图片和音乐仍由 TF 卡提供。手动亮度约 30 秒无用户操作后恢复自动；状态轮询不延长超时。光敏接线 A=J2-29、B=J1-16、C=J2-30，ADC 时钟保持 13.5 MHz。旧 Python 管理员协议不适用。

本次未引入依赖、兜底、兼容层、自动重试或降级逻辑，保留真实故障提示。新版需用户自行烧录；实际 HDMI 画面、光照响应、音频和断电重启仍需现场确认。没有新增待确认的设计项，也未采用更复杂的实现方案。
